# Decision Tree

## If requirements are unclear
- stop,
- ask questions,
- do not implement.

## If architecture is undefined
- force a design discussion,
- identify boundaries,
- reject coding.

## If failure modes are unknown
- block the change.

## If complexity is hidden
- document it,
- isolate it,
- reduce it,
- or refuse it.

## If the design cannot be defended
- it is not ready.
