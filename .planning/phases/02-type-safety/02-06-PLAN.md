# Plan 02-06 — Registry & PrescriptionForm Conversions

## Goal

Convert the 5 remaining JSX files to strict TSX. These are the highest-complexity group:
registries with Realtime subscriptions, filter state, and the PrescriptionForm with AbortController.

After this plan, `find src/features -name "*.jsx"` must return 0 results (except any excluded files).

| 1 | `employee-crud/OrganizationTelegramReport.jsx` | 240 | `Employee[]`, `getDaysDifference` fn type |

## Conversion recipe (same as prior plans)

1. Read source JSX fully
2. Create new `.tsx` with same content + TypeScript additions
3. Delete old `.jsx`
4. Run `npx tsc --noEmit` — fix any errors
5. Update any imports in other files that reference `.jsx` extension
